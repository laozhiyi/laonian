# 项目操作指南

## 如何新建 conda 环境

### 1. 创建新环境

打开终端（PowerShell 或 Anaconda Prompt），执行以下命令：

```bash
# 创建名为 xiaochengxu 的 conda 环境，指定 Python 版本
conda create -n xiaochengxu python=3.11 -y
```

### 2. 激活环境

```bash
# Windows
conda activate xiaochengxu

# Linux/Mac
source activate xiaochengxu
```

### 3. 安装依赖

进入后端目录并安装 Python 依赖：

```bash
cd e:\xiangmu\xiaochengxu2\backend
pip install -r requirements.txt
```

### 4. 验证安装

```bash
# 检查 Python 版本
python --version

# 检查关键依赖是否安装成功
pip show tortoise-orm
```

### 5. 设置 PyCharm/VSCode 使用该环境

**PyCharm:**
1. File -> Settings -> Project -> Python Interpreter
2. 点击齿轮图标 -> Add
3. 选择 Conda Environment -> Existing environment
4. 浏览找到 `anaconda3/envs/xiaochengxu/python.exe`

**VSCode:**
1. 按 `Ctrl+Shift+P`
2. 输入 `Python: Select Interpreter`
3. 选择 `xiaochengxu` 环境中的 Python

### 常见问题

**Q: 提示 conda 不是内部或外部命令？**
A: 需要先安装 Anaconda 或 Miniconda，并将其添加到系统 PATH 环境变量。

**Q: pip install 速度慢？**
A: 可以使用国内镜像源：
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 如何停止占用 8000 端口的进程

### 方法一：使用 netstat + taskkill（推荐）

1. **查找占用 8000 端口的进程**

```powershell
netstat -ano | findstr :8000
```

输出示例：
```
TCP    0.0.0.0:8000    0.0.0.0:0    LISTENING    12345
```

最后一列 `12345` 是进程 ID（PID）。

2. **根据 PID 终止进程**

```powershell
taskkill /PID 12345 /F
```

### 方法二：直接通过端口号终止进程

```powershell
for /f "tokens=5" %a in ('netstat -ano ^| findstr :8000 ^| findstr LISTENING') do taskkill /PID %a /F
```

### 方法三：使用 PowerShell（更简洁）

```powershell
# 查找并终止占用 8000 端口的进程
Get-NetTCPConnection -LocalPort 8000 -ErrorAction SilentlyContinue | ForEach-Object { 
    Stop-Process -Id $_.OwningProcess -Force -ErrorAction SilentlyContinue 
    Write-Host "已终止进程 ID: $($_.OwningProcess)" 
}
```

### 方法四：通过进程名称终止（如 uvicorn/fastapi）

```powershell
# 查找 uvicorn 进程
tasklist | findstr uvicorn

# 终止所有 uvicorn 进程
taskkill /IM uvicorn.exe /F

# 或者终止 python 进程（如果是 python 运行的）
taskkill /IM python.exe /F
```

### 常见问题

**Q: 提示"拒绝访问"？**
A: 需要以管理员身份运行 PowerShell。右键点击 PowerShell，选择"以管理员身份运行"。

**Q: 如何确认端口已释放？**
A: 执行以下命令验证：
```powershell
netstat -ano | findstr :8000
```
如果没有输出，说明端口已释放。

## 如何停止所有操作

### 停止后端服务

1. **停止 uvicorn 进程**
```powershell
taskkill /IM uvicorn.exe /F
```

2. **停止所有 python 进程（谨慎使用）**
```powershell
taskkill /IM python.exe /F
```

### 停止前端开发服务器

1. **停止 H5 开发服务器**
```powershell
# 在运行 npm run dev:h5 的终端按 Ctrl+C
```

2. **停止所有 node 进程（如果需要）**
```powershell
taskkill /IM node.exe /F
```

### 一键停止所有相关进程

```powershell
# 同时停止 uvicorn、node 和 python 进程
taskkill /IM uvicorn.exe /F
taskkill /IM node.exe /F
taskkill /IM python.exe /F
```

### 使用 PowerShell 脚本（推荐）

创建一个 `stop-all.ps1` 脚本：

```powershell
# stop-all.ps1
Write-Host "正在停止所有相关进程..."

# 停止后端服务
Get-Process -Name "uvicorn" -ErrorAction SilentlyContinue | Stop-Process -Force
Get-Process -Name "python" -ErrorAction SilentlyContinue | Stop-Process -Force

# 停止前端服务
Get-Process -Name "node" -ErrorAction SilentlyContinue | Stop-Process -Force

# 释放端口
Get-NetTCPConnection -LocalPort 8000 -ErrorAction SilentlyContinue | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force -ErrorAction SilentlyContinue }
Get-NetTCPConnection -LocalPort 3000 -ErrorAction SilentlyContinue | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force -ErrorAction SilentlyContinue }

Write-Host "所有进程已停止"
```

### 常见问题

**Q: 进程无法终止？**
A: 尝试以管理员身份运行 PowerShell，然后重新执行终止命令。

**Q: 如何查看还有哪些进程在运行？**
A: 执行以下命令：
```powershell
# 查看所有相关进程
tasklist | findstr "python node uvicorn"
```
